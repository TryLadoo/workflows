# Security

Please report security problems to **support@tryladoo.com**, with "Security" in the subject line. Don't open a public issue. Our disclosure policy is at https://tryladoo.com/security#disclosure.

This repo holds a file format, templates and an offline validator. A problem here is most likely a template that would make an agent share something it shouldn't, or a way to make the validator misbehave on a crafted file. Reports about the Ladoo platform itself are welcome at the same address.
